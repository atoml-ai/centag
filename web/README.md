# Centag Web UI

基于 Vue 3 + Element Plus 的 Centag 管理界面。

## 技术栈

- Vue 3 / TypeScript / Element Plus / Vite / Pinia / Vue Router / Axios

## 开发

```bash
cd web
npm install
npm run dev
```

生产构建（由根目录统一编排）：

```bash
# 从仓库根目录
make frontend   # → bin/server/static
```
