### 任务 1：数据库迁移脚本与 YAML 配置

| 属性 | 值 |
|------|----|
| 功能点 | 数据模型 |
| 前置依赖 | 无 |
| 难度 | S |
| 关联风险 | R04 |
| 验收标准 | `go test ./core/pkg/database/...` 迁移测试通过，YAML 文件可正确解析 |
| 风险缓解 | 使用 IF NOT EXISTS，支持幂等迁移 |

**执行步骤**：

1. 创建 `config/pricing/default.yaml` 默认计费规则文件：
   ```yaml
   version: "1.0"
   currency: "CNY"
   rules:
     - name: "Ollama 本地"
       backend_id: "ollama-local"
       model: "*"
       input_price_per_m: 0
       output_price_per_m: 0
       priority: 0
     - name: "PPIO DeepSeek V3.2"
       backend_id: "ppinfra"
       model: "deepseek-v3.2"
       input_price_per_m: 1.0
       output_price_per_m: 1.0
       priority: 100
   ```

2. 创建 PostgreSQL 迁移脚本 `031_pricing_rules.postgresql.sql`：
   ```sql
   CREATE TABLE IF NOT EXISTS pricing_rules (
       id BIGSERIAL PRIMARY KEY,
       name VARCHAR(100) NOT NULL,
       backend_id VARCHAR(100) NOT NULL,
       model VARCHAR(100) NOT NULL,
       input_price_per_m DECIMAL(12,6) NOT NULL,
       output_price_per_m DECIMAL(12,6) NOT NULL,
       currency VARCHAR(3) DEFAULT 'CNY',
       priority INT DEFAULT 0,
       enabled BOOLEAN DEFAULT true,
       created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
       updated_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
   );
   CREATE INDEX IF NOT EXISTS idx_pricing_rules_backend_model ON pricing_rules(backend_id, model);
   ```

3. 创建 PostgreSQL 迁移脚本 `032_token_usage_billing.postgresql.sql`：
   ```sql
   ALTER TABLE token_usage ADD COLUMN IF NOT EXISTS input_cost DECIMAL(12,6) DEFAULT 0;
   ALTER TABLE token_usage ADD COLUMN IF NOT EXISTS output_cost DECIMAL(12,6) DEFAULT 0;
   ALTER TABLE token_usage ADD COLUMN IF NOT EXISTS pricing_rule_id BIGINT;
   ```

4. 创建 SQLite 迁移脚本 `031_pricing_rules.sqlite.sql` 和 `032_token_usage_billing.sqlite.sql`

5. 编写 YAML 解析测试 `internal/billing/yaml_test.go`

6. 验证：`go test ./internal/billing/... -run TestYAMLParsing` 确认 YAML 解析正确

| 风险缓解 | 缓存 TTL + 主动失效机制 |

**执行步骤**：

1. 创建 `internal/billing/pricing_rule.go`，定义数据模型：
   ```go
   type PricingRule struct {
       ID               int64
       Name             string
       BackendID        string
       Model            string
       InputPricePerM   float64
       OutputPricePerM  float64
       Currency         string
       Priority         int
       Enabled          bool
       CreatedAt        time.Time
       UpdatedAt        time.Time
   }
   
   // PricingRulesFile YAML 文件结构
   type PricingRulesFile struct {
       Version   string         `yaml:"version"`
       Currency  string         `yaml:"currency"`
       UpdatedAt string         `yaml:"updated_at,omitempty"`
       Rules     []PricingRule  `yaml:"rules"`
   }
   ```

2. 创建 `internal/billing/store.go`，定义 Store 接口：
   ```go
   type Store interface {
       GetPricingRules(ctx context.Context) ([]*PricingRule, error)
       GetPricingRule(ctx context.Context, id int64) (*PricingRule, error)
       CreatePricingRule(ctx context.Context, rule *PricingRule) error

       DeletePricingRule(ctx context.Context, id int64) error
   ```

   - 重启后从 YAML 重新加载

5. 创建 `internal/billing/yaml_loader.go`，实现 YAML 加载逻辑：

6. 编写单测 `internal/billing/pricing_rule_test.go`

### 任务 3：计费服务核心逻辑

| 属性 | 值 |
|------|----|
| 功能点 | 计费规则引擎、Token 计量增强 |
| 前置依赖 | 任务 2 |
| 难度 | M |
| 关联风险 | R01, R02, R03, R07 |
| 验收标准 | `go test ./internal/billing/... -run TestBillingService` 全部通过 |
| 风险缓解 | 缓存机制 + 接口简洁 |

**执行步骤**：

1. 创建 `internal/billing/service.go`，定义 Service 接口：
   ```go
   type Service interface {
       ResolvePrice(ctx context.Context, backendID, model string) (*PriceInfo, error)
       EstimateCost(ctx context.Context, backendID, model string, inputTokens, outputTokens int) (*CostBreakdown, error)
       RecordUsage(ctx context.Context, req *RecordUsageRequest) (*UsageRecord, error)
       GetCostSummary(ctx context.Context, query *CostSummaryQuery) (*CostSummary, error)
   }
   ```

2. 创建 `internal/billing/service_impl.go`，实现核心逻辑：
   - 规则匹配：按 backend_id + model 查询，支持通配符 `*`
   - 优先级排序：priority DESC，相同 priority 取更精确的匹配
   - 缓存机制：TTL 5 分钟，规则变更时主动失效
   - 成本计算：`(input_tokens × input_price + output_tokens × output_price) / 1,000,000`

3. 创建 `internal/billing/types.go`，定义公共类型：
   ```go
   type PriceInfo struct { ... }
   type CostBreakdown struct { ... }
   type RecordUsageRequest struct { ... }
   type CostSummaryQuery struct { ... }
   type CostSummary struct { ... }
   ```

4. 编写单测 `internal/billing/service_test.go`，覆盖：
   - 精确匹配
   - 通配符匹配
   - 优先级排序
   - 缓存失效
   - 成本计算

5. 验证：`go test ./internal/billing/... -run TestBillingService`
