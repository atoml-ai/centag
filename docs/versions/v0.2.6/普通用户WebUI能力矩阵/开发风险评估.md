## 3. Critical / High 专项

### R01 — 深链编辑被守卫误伤

- **触发条件**：`path.startsWith('/pipelines')` 一律 redirect 到 dashboard。  
- **最坏结果**：普通用户无法打开画布/能力槽配置。  
- **缓解措施**：列表仅匹配精确列表路径；`create`/`/:id` 放行（T4）。  
- **验证方式**：路由单测 + 浏览器 U15（T8）。  
- **残余风险**：query/hash 变体——优先用 route name。可接受。

### R02 — Team Admin 无测试对话

- **触发条件**：admin 仍无测试入口。  
- **最坏结果**：违反硬条件。  
- **缓解措施**：T3 全角色 `pipelineTestChat`。  
- **验证方式**：浏览器 U12（team_admin）（T8）。  
- **残余风险**：无。

### R03 — 复制页面破坏复用

- **触发条件**：新建角色平行页。  
- **最坏结果**：三端漂移。  
- **缓解措施**：T1/T2 capability 导航；执行约束禁止平行页。  
- **验证方式**：`rg` + U19（T8）+ Step5 CR。  
- **残余风险**：少量 `v-if` 可接受。

### R04 — Team User 存储越权

- **触发条件**：仅藏导航未拦路由/API。  
- **最坏结果**：普通用户改存储。  
- **缓解措施**：T6 守卫 + API 核对/403。  
- **验证方式**：curl 403 + 浏览器 U07/U16（T8）。  
- **残余风险**：只读 GET 策略——实现时按禁写默认。可接受。

### R05 — UI 回归漏检

- **触发条件**：只跑 HTTP e2e 或 Browser 不可用仍宣称通过。  
- **最坏结果**：信息架构回潮。  
- **缓解措施**：T8 强制 `centag-ui-browser-test`；P0 fail/blocked 不准出。  
- **验证方式**：`/tmp/centag_ui_browser_results.json`。  
- **残余风险**：MCP 缺失 → blocked 不准出。可接受。
