| 属性 | 值 |
|------|----|

| 难度 | M |

3. 在 proxy 入口预留 `TriggerRequestHooks` / `TriggerResponseHooks` 调用点（可先 no-op 适配器）。
4. `go test ./core/pkg/hooks/...`

```bash
make test
```
