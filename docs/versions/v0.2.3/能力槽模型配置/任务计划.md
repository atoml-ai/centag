## 任务列表

### 任务 1：Capability Slot 契约与发现算法

| 属性 | 值 |
|------|----|
| 功能点 | F1 |
| 前置依赖 | 无 |
| 难度 | M |
| 关联风险 | R01 |
| 验收标准 | 1) 新增 `web/src/utils/capabilitySlots.ts`（或等价）；2) 单测/可运行断言覆盖：声明优先、`route_model_targets` 映射、发现仅含 router 目标节点；3) 杂散无 route_config 的 generator 不被发现 |
| 风险缓解 | 锁死发现白名单，防止误扫 |

**执行步骤**：

1. 实现 `CapabilitySlot` 类型与 `resolveCapabilitySlots(pipeline)`。  
2. 实现 `applyCapabilitySlotBindings(pipeline, rows)`（跟随默认 / 指定写回）。  
3. 用 vitest 或纯函数测例（若仓库无 vitest，可用最小 node 断言脚本或抽到可测纯函数并由 eslint 保证导出）——**优先**在现有前端工程可跑的方式补测；若无测试跑器，则提供 `capabilitySlots` 导出并由 T2 手工清单覆盖，同时在 `自测记录` 写清。  
4. 文档注释写清优先级：slots → route_model_targets → 发现。

| 属性 | 值 |
|------|----|
| 功能点 | F2 |
| 前置依赖 | 任务 1 |
| 难度 | M |

3. 删除或薄包装旧 `RouterModelAssignDialog` / `routeModelAssign.ts`。  
4. 空态引导：「请先在画布用新增分类添加分类」。
