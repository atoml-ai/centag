# Tray：desktop 命名 + 「运行」菜单

## 目标

1. GitHub Release 不再残留 `centag-proxyctl-*`；产品形态仅 **cli** / **desktop**（`centag-cli-*` / `centag-desktop-*`）。
2. 本地入口：`./start.sh run personal --desktop`；开发调试：`./start.sh debug personal --desktop`（先构建 + vite watch + debug 日志）；外壳二进制 `centag-desktop`（无 `--launcher*` / `--tray` 别名）。
3. 托盘「运行」→ WebUI `/agent-run`：主路径为复制 `centag wrap run` 命令；可选「在终端打开」（本机 sidecar 写 `.command`/`open`，非浏览器限制）。

## 接口

- `GET /api/v1/wrap/presets`
- `POST /api/v1/wrap/run`（`preset_id` / `argv` / `command`）

约束：需登录；仅 personal/minimal，或 loopback 客户端。
