## 任务列表

### 任务 1：i18n 基础设施搭建

| 属性 | 值 |
|------|----|
| 功能点 | G1, G2（vue-i18n 集成、语言包结构、偏好持久化到配置文件） |
| 前置依赖 | 无 |
| 难度 | M |
| 关联风险 | R04, R09, R13 |
| 验收标准 | 1. `npm run dev` 启动无报错；2. Header 语言切换功能可用；3. 语言选择保存到配置文件；4. Element Plus 分页/日期随语言变化；5. 缺 key 时 fallback 到 en |
| 风险缓解 | R04: 集成 Element Plus locale 和 dayjs locale；R09: 配置 `fallbackLocale: 'en'`；R13: 实现 `navigator.language` 映射逻辑 |

**执行步骤**：

1. 在 `web/package.json` 添加 `vue-i18n` 依赖
2. 创建 `web/src/i18n/index.ts` 配置文件（`createI18n`，`legacy: false`，`fallbackLocale: 'en'`）
3. 创建 `web/src/locales/en/`、`zh-CN/`、`ja/`、`ko/`、`ru/`、`es/` 目录结构
4. 创建基础语言包文件：`common.json`、`nav.json`、`layout.json`
5. 创建 `web/src/stores/locale.ts` 实现语言切换与后端 API 读写
6. 在 `internal/config/config.go` 添加 `UI.Locale` 配置字段
7. 在 `internal/handler/admin.go` 添加 locale 读写 handler
8. 在 `internal/server/router.go` 添加 `/api/v1/admin/config/locale` 路由
9. 在 `web/src/main.ts` 集成 `app.use(i18n)`
10. 在 `web/src/App.vue` 或 `WebLayout.vue` 添加 `ElConfigProvider` 绑定 Element Plus locale
11. 实现 Element Plus locale 映射（`epLocaleMap`）
12. 实现 dayjs locale 同步
13. 实现启动时自动检测逻辑：配置文件 → 浏览器语言 → 默认 `en`
14. 验证：`npm run dev` 启动 → Header 语言切换 → 刷新保持 → Element Plus 控件变化

6. 为 `nav` 域创建语言包 `web/src/locales/*/nav.json`
7. 创建 `web/src/components/LanguageSelector.vue` 页面底部上拉控件语言选择器

## 执行顺序

```
任务 1 (i18n 基础设施)
    ↓
任务 2 (导航布局) ──→ 任务 8 (测试验证)
    ↓
任务 3 (系统设置) ──→ 任务 4 (P0 页面) ──→ 任务 5 (其他页面) ──→ 任务 9 (体积检查)
    ↓
任务 6 (README 多语言) ──→ 任务 7 (截图资产)
    ↓
任务 10 (收尾文档)
```

**建议优先级**：
- **P0**：任务 1, 2, 3, 5, 6（核心功能）
- **P1**：任务 4, 8（全量覆盖 + 质量）
- **P2**：任务 7, 9, 10（资产 + 收尾）
