## 3. Critical / High 专项

### R01 — 文案抽取遗漏

- **触发条件**：某 view 未替换硬编码；或仅抽中文包、en 包缺 key 且 fallback 未开。
- **最坏结果**：英文界面大面积中文，推广演示失败。
- **缓解措施（编码前可做）**：建立页面→语言包域映射表；P0 页面清单锁定。
- **验证方式（可执行）**：`locale=en` 启动后对 `web/src/views` 做人工抽检；脚本 `rg '[\u4e00-\u9fff]' web/src/views --glob '*.vue'` 对比基线下降；缺失 key 依赖 fallback。
- **残余风险**：可接受（长尾帮助文案可 P2）。

### R02 — 导航/标题未国际化

- **触发条件**：只改了页面正文，未改 `utils/nav` 与 router meta。
- **最坏结果**：切换语言后顶栏仍中文。
- **缓解措施**：nav 类型改为 `labelKey`；Header 渲染强制 `t()`。
- **验证方式**：切换 `ja` 后顶栏与 `document.title` 非中文；`npm run test:nav` 通过。
- **残余风险**：可接受。

### R03 — 动态消息未走 i18n

- **触发条件**：`ElMessage.success('保存成功')` 等散落调用未改。
- **最坏结果**：操作反馈语言错乱。
- **缓解措施**：grep `ElMessage`/`ElMessageBox` 列入任务；统一 `t()`。
- **验证方式**：`rg "ElMessage\\.(success|error|warning)\\(['\"]" web/src` 趋近于 0（允许变量）。
- **残余风险**：可接受。

### R07 — 前端自测回归

- **触发条件**：selftest 断言中文 label。
- **最坏结果**：CI 红，阻塞合并。
- **缓解措施**：改断言为 key 或显式 locale。
- **验证方式**：`cd web && npm run test:ui-caps`。
- **残余风险**：可接受。

### R11 — 截图泄密

- **触发条件**：从真实环境截取含 API Key / 内网地址。
- **最坏结果**：密钥进 GitHub 历史。
- **缓解措施**：演示账号 + 假 Key；截图前打码检查清单。
- **验证方式**：人工审 `docs/assets/readme/*`；`rg -i 'sk-|api_key|Bearer' docs/assets/readme`（对文本元数据）。
- **残余风险**：可接受。

### R12 — 范围膨胀

- **触发条件**：要求翻译全部 `docs/guide` 或 Go 错误串。
- **最坏结果**：v0.3.0 无法按期发版。
- **缓解措施**：技术方案非目标；任务计划标 P0=UI+README。
- **验证方式**：任务计划无「全量 docs 翻译」项；CR 对照非目标。
- **残余风险**：可接受。
