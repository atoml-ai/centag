# 第三方 Agent 写配置对齐（cc-switch → Centag）

> 分支：`feature/v0.3.0`  
> 对照仓库：`/Users/caijun/workspaces/cc-switch`  
> 实现目录：`core/internal/agent/`、`web/src/views/AgentSetup.vue`

## 目标

在无法对所有 Agent 做深度适配的前提下，将 Centag「写配置接入」的路径、字段与写入模式对齐 cc-switch，并在接入页展示配置方法与官方安装链接，便于调试。

## 对照表

| Agent | 写入模式 | Centag 配置路径 | 关键字段 | 安装指引 |
|-------|----------|-----------------|----------|----------|
| Claude Code | overwrite（合并 env） | `~/.claude/settings.json` | `env.ANTHROPIC_BASE_URL` / `AUTH_TOKEN` / `MODEL` | https://code.claude.com/docs/en/install |
| Claude Desktop | overwrite | macOS/Win：Claude + Claude-3p gateway profile | `inferenceGateway*`、`deploymentMode=3p` | https://claude.ai/download |
| Codex CLI | overwrite | `~/.codex/auth.json` + `config.toml` | `OPENAI_API_KEY`、`model_providers.custom.base_url` | https://github.com/openai/codex |
| Gemini CLI | overwrite | `~/.gemini/.env` + `settings.json` | `GEMINI_*`、`security.auth.selectedType` | https://github.com/google-gemini/gemini-cli |
| Grok Build | overwrite | `~/.grok/config.toml` | `[models]` / `[model."centag"]` | https://x.ai/cli |
| OpenCode | **merge** | `~/.config/opencode/opencode.json` | `provider.centag`、`model` | https://opencode.ai |
| OpenClaw | **merge** | `~/.openclaw/openclaw.json` | `models.providers.centag`、`agents.defaults.model.primary` | https://www.npmjs.com/package/openclaw |
| Hermes | **merge** | `~/.hermes/config.yaml` | `model.*`、`custom_providers[name=centag]` | https://github.com/NousResearch/hermes-agent |
| CodeBuddy | **merge** | `~/.codebuddy/models.json` | `models[].url`（须含 `/chat/completions`）、`apiKey`、`id` | https://www.codebuddy.ai/docs/zh/cli/models |
| WorkBuddy | **merge** | 同上（共用 models.json） | 同上；也可 UI「设置 → 模型」 | https://www.codebuddy.ai/docs/zh/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model |
| TRAE | **merge**（尽力） | `Trae` / `Trae CN` 的 `User/settings.json` → `trae.customModels` | Base URL=`…/v1`（关闭完整 URL）；模型 ID=`centag/<pipeline>` | https://docs.trae.ai/ide/models?_lang=zh |

TUI / Web Agent：`write_mode=none`，不写本地配置。

## 相对旧实现的修正

1. Claude Code：不再写 `~/.claude.json` / Append `.env`，改为 settings.json env。
2. Claude Desktop：修正 macOS/Windows 路径，写入 3P gateway profile（非 `~/.config/Claude`）。
3. Grok：`~/.grok-build` + Codex 风格 → `~/.grok/config.toml` 原生格式。
4. Gemini：补写 `settings.json` auth selectedType。
5. OpenCode / OpenClaw / Hermes：整文件覆盖 → 累加合并。
6. OpenCode：只写 `opencode.json`，不再双写 jsonc。
