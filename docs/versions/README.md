# 版本归档

按版本存放需求产物（技术方案、任务计划、自测记录、CR 报告）。

```
docs/versions/
├── README.md          # 本文件
└── vX.Y/
    └── <需求名>/
        ├── workflow_state.md
        ├── 技术方案.md
        ├── 任务计划.md
        └── …
```

历史 Centag 版本文档已在 Centag 首提前清理；新需求从本目录重新归档即可。
