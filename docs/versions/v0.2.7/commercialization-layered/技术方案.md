# 技术方案 — 商业化分层（插件式 Open Core）

> 版本：v0.2.7 | 日期：2026-07-20  
> 修订：2026-07-20 — **目标态**：开源仅 minimal/personal；Team 主程序与插件在 `centag-pro`；开源删除 `dist/team`

## 1. 背景与目标

### 1.1 目标

| 原则 | 含义 |
|------|------|
| 开源自立 | `minimal` / `personal` 源码、依赖、构建、CI **零**接触 `centag-pro` |
| 商业扩展 | Team（及未来 Enterprise）= 开源核心 + **pro 插件包**，仅构建商业 SKU 时引入 |
| 插件接入 | pro 内功能以 `extension.Plugin` +（前端）Web Pack 注册 |
| 缺 pro 失败 | 指定 team 但无 pro → **构建失败**，不产出残缺二进制 |

### 1.2 非目标（本阶段）

- E0/E1 **不**完成存量多租户代码整包迁出（E2+）
- E0/E1 **不**完成 team 前端 pack 迁出（E3）
- 不把计费规则查看等 personal 已用能力迁入 pro

### 1.3 仓库与依赖方向

```text
centag (OSS)                         centag-pro (private)
├── dist/minimal|personal              ├── cmd/centag-team     ★ Team main
├── core/pkg/extension  Host           ├── bundle/team         SKU 组合
├── core/pkg/editionmodule             ├── plugins/team|…     商业插件
├── web/ (personal/minimal)            └── web/packs/*         前端包（E3）
└── start.sh build team → 转调 pro
```

**依赖边：仅 `centag-pro → centag`。开源模块图无私有边。**

**分支同步（强制）：** `centag-pro` 与 `centag` **使用相同分支名**（如双方均为 `feature/v0.2.7`），随主仓开分支/合并/打 tag 对齐。`build-team.sh` 检测不一致并警告；`CENTAG_PRO_STRICT_BRANCH=1` 时构建失败。

## 2. 方案选型

| 方案 | 说明 | 结论 |
|------|------|------|
| A：开源 `dist/team` require pro | 开源出现私有边 | 否 |
| B：开源 stub + overlay | 假 team 壳，切分不干净 | 否（已废弃） |
| **C：Team main 在 pro；开源删 dist/team** | 完美切分；start.sh 可转调 | ⭐ |

## 3. 详细设计

### 3.1 后端 Extension Host

- 包：`centag/core/pkg/extension`
- `Plugin`：`Name()` + `Init(Host)`
- `Host`：白名单能力（E0：`Edition()`；后续 RegisterHook / Admin 等）
- 商业包 `init()` → `extension.Register`；team 二进制 blank-import `bundle/team`
- 并存：`editionmodule` 继续承载 admin 增量路由（`/api/v1/admin/pro`）

### 3.2 Team 构建

| 入口 | 行为 |
|------|------|
| `centag-pro/scripts/build-team.sh` | `go build ./cmd/centag-team` → `bin/centag-team` |
| `centag/start.sh build team` | 解析 `CENTAG_PRO_PATH` 或 `../centag-pro`，转调上述脚本；否则失败 |
| `start.sh` Docker team | E1：拒绝并提示改在 pro 构建 |

### 3.3 前端（E3）

- 开源 `web/` = Host，仅 personal/minimal
- pro `web/packs/*` = 商业包；team 前端构建在 pro 执行

### 3.4 能力迁移节奏

| 阶段 | 内容 |
|------|------|
| **E0** | Host SDK + 单测 |
| **E1** | pro `cmd/centag-team` + bundle；开源删 `dist/team`；start.sh 转调 |
| **E2** | 迁 team 后端产品代码进 `plugins/team` |
| **E3** | 迁 team Web 进 packs |
| **E4** | CI 双轨 + 第二插件空壳证明扩展路径 |

## 4. 兼容性

- personal / minimal：行为与构建路径不变（无 pro）
- 原开源 `dist/team`：删除；文档与脚本指向 pro
- 存量 `CENTAG_EDITION=team` 运行时能力：E2 前仍主要在开源核心；E2 后由插件承载产品面
