## 执行约束

- **开源可改**：`core/pkg/extension`、Host 原语 facade（`authapi` 等）、`editionmodule`、`server`（拆路由）、文档；**禁止** `centag-pro` 依赖边；**禁止**开源 `pkg/teamadmin` 类产品包（D6）
- **pro 可改**：`cmd/centag-team`、`bundle/*`、`plugins/team`、`internal/teamadmin`、`module/`、构建脚本；**禁止**平行重写多租户 CRUD（必须剪切）
- **不可**：在开源留下可阅读的 team 管理面源码；勿把 `cost/summary`、`billing/rules`、用户自服务迁入 pro
- **分支**：`centag-pro` 与开源同名分支（`feature/v0.2.7`）
- **遵循**：`docs/harness/CONVENTIONS.md`、`docs/harness/ARCHITECTURE.md`

### 留开源（禁止迁）

| 面 | 理由 |
|----|------|
| 认证 / profile / 自管 API Key / 用户 token-usage | personal 必需 |
| `GET /api/v1/admin/cost/summary`、`/billing/rules*` | 技术方案非目标；personal 已用 |
| backends / pipelines / storage / cache / 对话 Store | Dist 矩阵共用；仅 runtime 租户过滤 |
| `TenantID` 作用域原语、DB schema / migrations | 基础设施；避免破坏升级路径（R06） |
| `useraccess` 过滤点嵌入 handlers | **本波**：实现留开源 + `Applies(IsTeam)`；不整包进 pro |
| AB 流水线节点 + Persist 钩子 | 仅 Admin 查询面迁出 |

### 产品决策

| # | 决策 | 值 |
|---|------|------|

## E2 — 后端产品代码迁出（本波）

### E2.0 — 扩展 Host / editionmodule 契约（开源）

| 属性 | 值 |
|------|----|
| 功能点 | 插件可挂原路径 + 注入 deps + 注册中间件/钩子 |
| 前置依赖 | E1 完成；`centag-pro` 切到 `feature/v0.2.7` |
| 难度 | M |
| 关联风险 | R03、R13 |
| 验收标准 | `go test ./core/pkg/extension/... ./core/pkg/editionmodule/...` 通过；Host 文档注释列出白名单方法 |
| 风险缓解 | 白名单增长需注释+单测；禁止把业务逻辑写进 Host |

**执行步骤**：

1. 扩展 `extension.Host`（建议最小集）：
   - 已有：`Edition()`
   - 新增：`RegisterTeamAdminRoutes(fn)`、`RegisterUserRoutes(fn)`（或等价：暴露 `TeamAdmin` / `UserJWT` `*gin.RouterGroup`）
   - 新增：`RegisterProtectedMiddleware(mw)`（配额）
   - 新增：`RegisterBillingHook(hook)` 或注入 `HookManager`
   - 新增：`Deps()` → 充实后的 `HostDeps` / 与 `editionmodule.AdminDeps` 对齐（DB stores、BackendManager、PipelineRegistry、TokenUsage、Auth helpers 等——仅接口/指针，不含业务）
2. Server 在路由组装阶段构造真实 Host，再 `extension.InitAll`（或提供 `BindRoutes` 二阶段），保证 deps 非空
3. `editionmodule`：`/admin/pro` 继续增量；**不**把存量 CRUD 塞进 `/pro`
4. 单测：假插件注册路由/中间件；无插件时零副作用
