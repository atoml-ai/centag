### 类别说明

| 类别 | 关注点 |
|------|--------|
| 实现 | 接口未接线、双写、循环依赖、分层违规 |
| 集成 | 发行版差异、钩子顺序、流式/非流式路径不一致 |
| 迁移 | 表结构、删旧代码遗漏引用、兼容旧配置 |
| 回归 | 计量翻倍、路由误判、代理主路径被阻断 |
| 性能 | 同步写库拖慢、文件锁、批处理堆积 |
| 安全 | 越权读会话、日志含敏感原文、配额绕过 |
| 排期 | 范围膨胀、P0/P1 边界不清 |
