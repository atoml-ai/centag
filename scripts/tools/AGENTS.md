# scripts/tools/ — 工具目录

> 面向 Agent：本目录包含辅助工具脚本。

## 目录职责

存放长期运行的工具脚本，如守护进程。

## 核心文件

| 文件 | 用途 |
|------|------|
| `daemon.sh` | 守护进程脚本 |

## 使用方式

```bash
# 以守护进程方式启动
make daemon

# 调试模式
make daemon-debug
```

## 约束

- ❌ **禁止**工具脚本修改生产数据
- ✅ **允许**：添加新工具
- ✅ **必须**：工具有使用说明
